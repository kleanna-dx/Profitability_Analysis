개인 규칙이란?

AI 챗봇은 대화가 끝나면 이전 대화 내용을 기억하지 못합니다. 예를 들어 "앞으로 rt는 두루마리로 불러줘"라고 알려줘도, 새 대화창을 열면 잊어버립니다. 이 페이지에 저장한 규칙은 당신 계정으로 질문할 때마다 AI에게 자동으로 알려주기 때문에 AI가 계속 기억하는 것처럼 동작합니다. (내 계정에만 적용됩니다. 다른 사용자에게는 영향 없음)

규칙 등록/관리 방법
  • 등록은 채팅 화면에서 "앞으로 rt는 두루마리로 불러줘" 처럼 대화로만 가능합니다. (AI가 자동으로 감지해 저장)
  • 이 화면에서는 저장된 규칙을 확인 · 잠시 끄기 · 삭제만 할 수 있습니다.
  • 규칙 내용을 바꾸고 싶으면 기존 규칙을 삭제한 뒤 채팅에서 다시 말해 주세요.
이런 규칙은 저장할 수 있어요
  • 내가 쓰는 별명 알려주기 — 예: "rt는 두루마리를 뜻해"
  • 질문할 때 원하는 결과 형태 — 예: "매출 물어볼 때는 영업이익율도 같이 보여줘"
  • 지표를 볼 때 개인 선호 — 예: "상위 10개만 정렬해서 보여줘"
이런 규칙은 저장할 수 없어요
  • 회사 공식 계산식을 개인이 바꾸는 것 — 예: "내 계정에서는 영업이익율을 (매출–원가)÷매출로 계산해"
    → 지표 계산식은 회사 전체가 공유하는 공식 규칙이라 개인이 바꾸면 부서 간 숫자가 안 맞습니다. 계산식 변경이 필요하면 학습관리 담당자에게 요청해 주세요.
  • 표준 용어의 뜻 자체를 뒤바꾸는 것 — 예: "매출을 '이익'이라고 부르자"
사용자당 최대 50개까지 활성화할 수 있으며, 초과 시 아래 목록에서 불필요한 규칙을 삭제하면 됩니다.
